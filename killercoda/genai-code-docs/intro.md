# GenAI Code + Docs — AI as a Coding and Documentation Partner

This is an **instructor-led demo** for the Engineering 5.0 Faculty Development Program.

## What this demo shows

A single prompt is sent to Claude asking it to implement a CPU scheduler, explain every function in plain English, and generate technical documentation. Watch all three outputs arrive in real time.

The goal: show what GenAI changes about the engineering workflow. The AI produces the first draft. The engineer validates, decides, and takes responsibility.

## What you will run

| Step | What happens |
|------|-------------|
| 1 | Set your Anthropic API key and verify the connection |
| 2 | Generate a full Round Robin CPU scheduler implementation |
| 3 | Generate plain-English explanation + technical documentation |
| 4 | Run a variation to show generalization |

## Setup happening in the background

Python 3 and the Anthropic SDK are being installed right now. The demo scripts are also being prepared. This takes about 30–60 seconds.

> **For the instructor:** Once the terminal prompt appears, proceed to Step 1. Keep this lab open on your machine during the session — the audience watches your screen.
