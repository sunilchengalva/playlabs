# Demo Complete — GenAI Code + Docs

## What just happened

You gave Claude a single prompt. It produced:

- A complete, working **Python implementation** of a CPU scheduler
- A **plain-English explanation** of every function — suitable for a first-year student
- **Technical documentation** in standard format — ready for a codebase or handout
- A **variation** for a different algorithm — using the same prompt structure

All in a few minutes of terminal time.

## The core insight for engineering education

GenAI changes **where the work starts**, not **whether engineering judgment is needed**.

Before: students start from a blank file.
After: students start from a generated draft and must validate, improve, and take responsibility for it.

The engineering skill does not disappear. It becomes more visible — because the AI makes an explicit first attempt that the engineer must critically evaluate.

## The accelerated computing connection

The speed you just witnessed — responses in under 20 seconds — is entirely dependent on GPU-accelerated inference. Without the hardware infrastructure covered in this session, that same model would take minutes to respond. Speed of inference is what makes AI a real-time collaborator, not just a batch tool.

## What to build in your curriculum

One change that requires no approval: take an existing assignment and add this instruction:

> *"Here is what Claude produced for this problem. Find one thing it got right, one design decision you would change, and one edge case it missed."*

That single question tests more engineering skill than the original assignment.
