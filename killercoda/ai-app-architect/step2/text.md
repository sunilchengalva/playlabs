# Step 2 — Run the App Design Demo

This is the main demo. Run the script and watch Claude generate a full app architecture from a single sentence.

## Run the demo

```
python3 /root/demo/app_architect.py
```

## What you will see

Claude will stream the response live — you will see it build in real time:

1. **User Flow** — 5–6 step user journey
2. **Key Screens** — each screen with its purpose
3. **Component Architecture** — frontend components and responsibilities
4. **Database Schema** — main tables with key fields

## What to narrate while it runs

Point out these moments to the audience:

- **When the structure appears** — "Notice it organised the output into four sections without being told the format explicitly"
- **When you see the database schema** — "Where did the time quantum / field names come from? The AI made design decisions. Are they the right ones for your context?"
- **At the end** — "This took 15 seconds. A human architect would take 30–45 minutes for the same scaffolding. What changes is that the engineer now starts from a draft, not a blank page."
