# AI App Architect — GenAI as a Software Engineering Collaborator

This is an **instructor-led demo** for the Engineering 5.0 Faculty Development Program.

## What this demo shows

A single one-line product brief is sent to Claude (Anthropic's AI). Watch it produce a complete software architecture — user flow, key screens, component design, and database schema — in real time.

The goal is not to show that AI replaces engineers. It is to show what **Engineering 5.0 collaboration** looks like in practice: AI handles the scaffolding, the engineer handles the judgment.

## What you will run

| Step | What happens |
|------|-------------|
| 1 | Set your Anthropic API key and verify the connection |
| 2 | Run the main demo — AI designs a Student Attendance Tracker app |
| 3 | Modify the brief and run again to show adaptability |

## Setup happening in the background

Python 3 and the Anthropic SDK are being installed right now. The demo script is also being prepared. This takes about 30–60 seconds.

> **For the instructor:** Once the terminal prompt appears, proceed to Step 1. Keep this lab open on your machine during the session — the audience watches your screen.
